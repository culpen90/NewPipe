## বিৱৰণ

Rillvoro এ আপুনি ব্যৱহাৰ কৰা সেৱাৰ অফিচিয়েল API (যেনে PeerTube) ৰ পৰা প্ৰয়োজনীয় তথ্য আনি কাম কৰে।  যদিও আমাৰ উদ্দেশ্যৰ বাবে অফিচিয়েল API নিষিদ্ধ (যেনে YouTube), বা মালিকানাধীন, এপটোৱে ৱেবছাইটটো বিশ্লেষণ কৰে বা ইয়াৰ পৰিৱৰ্তে এটা আভ্যন্তৰীণ API ব্যৱহাৰ কৰে।  ইয়াৰ অৰ্থ হ'ল Rillvoro ব্যৱহাৰ কৰিবলৈ কোনো সেৱাত একাউণ্টৰ প্ৰয়োজন নাই। লগতে, যিহেতু ই বিনামূলীয়া আৰু মুক্ত উৎস(Open Source) চফ্টৱেৰ, এপ বা এক্সট্ৰেক্টৰে কোনো মালিকানাধীন লাইব্ৰেৰী বা ফ্ৰেমৱৰ্ক ব্যৱহাৰ নকৰে, যেনে গুগল প্লে সেৱা।  অৰ্থাৎ আপুনি এনে ডিভাইচ বা কাষ্টম ৰমত Rillvoro ব্যৱহাৰ কৰিব পাৰে যিবোৰত গুগল এপ ইনষ্টল কৰা হোৱা নাই।

## ইনষ্টল আৰু আপডেটসমূহ

ডিবাগ APK নিৰ্মাণ কৰিবলৈ JDK 21 আৰু Android SDK ইনষ্টল কৰি তলৰ কমাণ্ডসমূহ চলাওক।

```sh
git clone https://github.com/culpen90/Rillvoro.git
cd Rillvoro
./gradlew :app:assembleDebug
```

ডিভাইচটো সংযোগ কৰি USB ডিবাগিং সক্ৰিয় কৰক আৰু এই কমাণ্ডটো চলাওক

```sh
./gradlew :app:installDebug
```
