## しちめい

じゆうなコピーレフトソフトウェアぬRillvoroーいっさいぬGoogleフレームワークライブラリうゆび、YouTube APIさしましん。ウェブサイトーふぃちぐとーるじょうほうぬたみてーぬんかいゆみくまりーるたみ、くぬアプレーGoogleぬサービスぬインストールさりてぃうぅらんたんまちっししようぬなやびーん。また、RillvoroぬしようんかいYouTubeアカウントーふぃちようとぅなやびらん。

## インストールとぅこうしん

デバッグ APK んかい JDK 21 とぅ Android SDK が必要やいびーん。

```sh
git clone https://github.com/culpen90/Rillvoro.git
cd Rillvoro
./gradlew :app:assembleDebug
```

USB デバッグ

```sh
./gradlew :app:installDebug
```
